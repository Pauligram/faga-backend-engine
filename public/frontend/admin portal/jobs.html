Production Integration Notes
Backend endpoints and security requirements for this page.

Recommended API endpoints

  • GET /api/admin/jobs
  • GET /api/admin/jobs/:jobId
  • POST /api/admin/jobs
  • PATCH /api/admin/jobs/:jobId
  • POST /api/admin/jobs/:jobId/publish
  • POST /api/admin/jobs/:jobId/close
  • POST /api/admin/jobs/:jobId/approve
  • DELETE /api/admin/jobs/:jobId
  • GET /api/admin/jobs/:jobId/applications
  • GET /api/admin/jobs/export

Backend requirements

  • Enforce administrator authentication and RBAC server-side.
  • Never trust status, employer, salary, vacancy or deadline values supplied by the browser.
  • Validate and sanitize every job field on the server.
  • Record create, edit, approve, publish, close and delete operations in the audit log.
  • Use server-side pagination, filtering and sorting for production data.
  • Do not expose private applicant CV files through permanent public URLs.
  • Preserve historical job/application records according to the retention policy.
  • Require confirmation and appropriate permissions for destructive operations.
  • Use idempotency controls for actions that can be retried.
  • Employer and hiring decisions remain separate from applicant platform access.
